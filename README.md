# PIA-wrapper

A wrapper app for PIA-related functionality.

**Files**
- **app.py**: Main application entrypoint — starts and runs the app.
- **constants.py**: Stores configuration values and constants used across the app.
- **utils.py**: Helper functions used by the application.
- **assets/**: Static files (CSS, images) used for the app's UI and styling.

**Run Locally**
1. Create and activate a virtual environment (PowerShell):

```powershell
python -m venv venv
.\venv\Scripts\Activate
```

2. Install dependencies:

```powershell
pip install -r requirements.txt
```

3. Run the app:

```powershell
python app.py
```

The app should now be running locally.
